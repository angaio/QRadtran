# QRadtran インストール・操作説明書

**バージョン** 0.3.0　　**日付** 2026-09-19　　**発行** Wuhan WaveFront Co., Ltd.

本説明書は 简体中文・English・Русский・한국어・Français・Deutsch・Español 版もあります。インストール後、すべての版がインストール先の `doc\` フォルダーに置かれます。

QRadtran は赤外線・光電システム技術者向けの大気透過率・放射輝度計算ソフトウェアです。Windows 上のグラフィカルな画面で、斜め経路および水平経路の分光透過率、経路放射輝度と天空放射輝度、目標の見かけ放射輝度を計算します。複数曲線の比較、パラメータ掃引によるルックアップテーブル生成（CSV / HDF5）、コマンドラインツール、Python インターフェースに対応しています。計算カーネルはオープンソースの libRadtran で、ソフトウェアと一緒にインストールされるため追加の設定は不要です。

## 1. 動作環境

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11、64 ビット |
| CPU | 4 コア以上。カーネルは複数プロセスを並列実行するため、コア数が多いほどバッチ計算が速くなります |
| メモリ | 8 GB 以上 |
| ディスク | インストール後約 1.2 GB（3 段階すべての分解能のスペクトル表を含む）。細分解能の計算は読み込み量が多いため SSD を推奨 |
| 画面 | 1600 × 900 以上 |
| その他 | Python・MSYS2・WSL は不要。VC++ ランタイムは同梱 |

Python インターフェースは任意機能で、システムの Python 3.10 64 ビットと numpy が必要です。

## 2. インストール

1. `QRadtran-0.3.0-Setup-x64.exe` をダブルクリックします。
2. インストーラーの言語（简体中文、English、Русский、日本語、한국어、Français、Deutsch、Español）を選びます。選んだ言語はソフトウェアの表示言語として記録され、後から「ツール → 設定」で変更できます。
3. サードパーティライセンスの説明を読み、「次へ」をクリックします。
4. インストール先を選びます。既定は `C:\Program Files\QRadtran` です。パスに日本語を含めても構いませんが、ネットワークドライブは推奨しません。
5. 追加タスク：
   - **デスクトップにショートカットを作成**：既定でオン。
   - **インストールフォルダーを PATH に追加**：既定でオフ。オンにすると任意のコマンドプロンプトから `qradtran-cli` を実行できます。
6. 「インストール」をクリックし、ファイルのコピー（1〜3 分）を待ちます。
7. 完了ページからソフトウェアの起動や本説明書の表示ができます。

インストーラーには管理者権限が必要です。現在のユーザーだけにインストールする場合は権限の確認で「自分専用にインストール」を選びます。その場合の既定フォルダーは `%LOCALAPPDATA%\Programs\QRadtran` になります。

### インストール不要で使う

インストーラーを使わず、配布フォルダー `QRadtran\` 全体を任意の場所にコピーして `QRadtran.exe` を直接実行することもできます。依存ファイルはすべてフォルダー内にあり、フォルダーを削除すればアンインストール完了です。

## 3. 初回起動

起動したら、まずウィンドウ右下のステータスバーを確認します：

```
カーネル libradtran 2.0.6 | 7 プロセス
```

この表示があれば計算カーネルは準備完了です。「プロセス」は同時に実行するカーネルプロセス数です。「カーネルを利用できません」と表示される場合は「ツール → 設定」でカーネルのパスを確認してください（第 10 節）。

**表示言語**：既定では Windows の表示言語に従い、簡体字中国語・英語・ロシア語・日本語・韓国語・フランス語・ドイツ語・スペイン語に対応します。「ツール → 設定 → 表示言語」で選択して再起動すると反映されます。コマンドライン引数で一時的に指定することもできます（例：`QRadtran.exe --lang ja`）。

初回はプリセットシナリオから始めることをお勧めします：

1. メニュー「ファイル → プリセットシナリオを読み込む…」で `mls_ground_to_air_3_5um.json`（中緯度夏の大気、地上から高度 10 km の目標を見る、3〜5 µm）を選びます。
2. ツールバーの「実行」をクリックするか F5 を押します。
3. 下部の「ジョブとログ」にジョブが 1 行現れ、進捗バーが完了すると中央に曲線が表示されます。青は透過率（左軸）、暖色は放射量（右軸）です。所要時間は約 7 秒です。

### ツールバー

| ボタン | 機能 |
|---|---|
| 新規 / 開く / プロジェクトを保存 | プロジェクトは全パラメータと計算済み結果を保存する 1 つの JSON ファイルです |
| プリセットシナリオを読み込む | 同梱の 3 つのサンプルシナリオ。名前は表示言語に従います |
| 実行（F5） | 現在のパラメータで計算し、結果を既存の曲線に追加します（上書きしません） |
| すべて停止 | 実行中のジョブをすべてキャンセルします |
| パラメータ掃引 / LUT | バッチ計算ダイアログを開きます（第 7 節） |
| 画像を出力 | 現在のグラフを PNG / PDF / JPEG で保存します |
| ズームをリセット（Home） | グラフを全範囲に戻します |
| X 軸 | 横軸の単位：µm / nm / cm⁻¹。切り替えは即時反映 |
| スペクトル密度 | 放射量のスペクトル密度単位：µm あたり / nm あたり / cm⁻¹ あたり |

### グラフの操作

| 操作 | 効果 |
|---|---|
| マウスホイール | カーソル位置を中心にズーム |
| ドラッグ | パン |
| ダブルクリック | リセット |
| マウス移動 | 下段とステータスバーにカーソル位置の各曲線の値を表示 |
| 曲線パネルのチェックボックス | 曲線の表示 / 非表示 |
| 色見本をダブルクリック | 曲線の色を変更 |
| 結果名を右クリック | その結果を CSV に出力、または削除 |

透過率は左軸（0〜1）、放射輝度と放射照度は右軸に描かれるため、重ねて表示できます。

## 5. パラメータパネルの詳細

### 5.1 大気

| 項目 | 説明 |
|---|---|
| 標準大気 | 熱帯、中緯度夏、中緯度冬、亜北極夏、亜北極冬、米国標準大気 1976（AFGL の 6 種）、またはカスタムプロファイル |
| プロファイルを読み込む (CSV) | 独自の気圧・気温・湿度の高層観測データを読み込みます（下記参照） |
| 水蒸気カラム量 | オンにすると可降水量を指定のミリメートルに合わせてスケーリングします。オフなら標準大気の値を使用 |
| オゾンカラム量 | 同上、単位 DU |
| CO₂ 混合比 | ppm、既定 420 |

**カスタムプロファイルのファイル形式**：CSV または空白区切りテキストで、先頭行は列名です。必須列は高度・気圧・気温と湿度列 1 つ。認識する列名（大文字小文字区別なし）：

| 量 | 列名 | 単位 |
|---|---|---|
| 高度 | z, alt, altitude, height | km（`z_m` ならメートル） |
| 気圧 | p, pres, pressure | hPa（`p_pa` なら Pa） |
| 気温 | t, temp, temperature | K（`t_c` なら ℃） |
| 湿度（いずれか 1 つ） | rh；q；h2o / h2o_vmr | 相対湿度 %；比湿 g/kg；体積混合比 ppmv |
| オゾン（任意） | o3, o3_vmr | ppmv |

例：

```
z_km,p_hpa,t_k,rh
0.0,1013.0,295.0,70
1.0,900.0,289.0,65
2.0,795.0,283.0,55
5.0,540.0,262.0,40
10.0,265.0,223.0,20
```

読み込んだプロファイルより上の高度は、選択した標準大気で補完されます。

### 5.2 幾何

| 経路の種類 | 意味 | 関連パラメータ |
|---|---|---|
| 斜め経路（観測者→目標） | 観測者と目標の高度が異なる | 観測者高度、目標高度、観測天頂角 |
| 水平経路 | 観測者と目標が同じ高度 | 観測者高度、水平経路長 |
| 全層鉛直 | 地表から大気上端まで | なし |
| 天空放射輝度のみ | 目標なし。ある方向の天空放射輝度を見る | 観測者高度、観測天頂角、方位角 |

角度の規約：

- **観測天頂角**：0° が真上、90° が水平、180° が真下。目標が観測者より上なら 90° 未満、下なら 90° 超でなければならず、そうでない場合はパネルがエラーを表示します。
- **観測方位角**、**太陽方位角**：北を 0°、時計回り。
- **太陽天頂角**：太陽波長域の放射量にのみ影響し、透過率には影響しません。
- **地表標高**：大気プロファイル最下端の高度。観測者・目標の高度は海抜です。

天頂角が 85°〜95° の場合、ほぼ水平な経路として層別消散積分に切り替わり、精度に関する警告が表示されます。

### 5.3 エアロゾルと雲

| 項目 | 説明 |
|---|---|
| エアロゾルの種類 | なし、田園、都市、海洋、対流圏（Shettle モデル）、または OPAC 混合 |
| 視程 | 地上水平視程（km）。境界層のエアロゾル濃度を決めます |
| 季節 | 春夏 / 秋冬プロファイル |
| 成層圏エアロゾル | 背景 / 中程度の火山性 / 強い火山性 / 極端な火山性 |
| OPAC 混合名 | OPAC 選択時に指定。例：continental_average、maritime_clean、urban、desert |
| 単層の雲 | 水雲または氷雲。雲底・雲頂・含水量・有効半径を指定 |

### 5.4 地表

| 項目 | 説明 |
|---|---|
| 地表アルベド | 太陽波長域用、0〜1 |
| 地表温度 | 熱赤外域の地表放射温度 |
| 地表放射率 | 熱赤外域用、0〜1 |

### 5.5 スペクトル

| 項目 | 説明 |
|---|---|
| スペクトル単位 | µm / nm / cm⁻¹。切り替え時に開始・終了値は自動換算 |
| 開始 / 終了 | スペクトル範囲。太陽域（≤ 5 µm）と熱赤外域（≥ 2.5 µm）を別々にカーネルへ渡し、結果を結合します |
| 出力刻み | 出力グリッド間隔。0 ならカーネルの代表波長グリッドをそのまま使用 |
| バンドモデル分解能 | 粗 15 cm⁻¹ / 中 5 cm⁻¹ / 細 1 cm⁻¹ / LOWTRAN 20 cm⁻¹。細かいほど高精度で低速 |
| ソルバー | DISORT（多重散乱、既定）または二流近似。放射輝度が必要な場合は自動的に DISORT に切り替わります |
| DISORT ストリーム数 | 既定 16。散乱の強い条件（濃いエアロゾル、雲）では 32 に増やせます |

所要時間の目安（4 コアのオフィス PC）：3〜5 µm 地対空で粗分解能約 7 秒、中分解能約 30 秒。8〜12 µm 水平 1 km で約 2 秒。

### 5.6 出力項目

| 項目 | 意味 | 単位 |
|---|---|---|
| 経路透過率 | 観測者から目標までの分光透過率 | 無次元 |
| 経路放射輝度 | 経路上の大気自身の放射と散乱が視線に入る放射輝度 | W/(m²·sr·cm⁻¹)、切り替え可 |
| 天空放射輝度 | 観測者位置で視線方向に見える天空放射輝度 | 同上 |
| 直達 / 下向き散乱 / 上向き放射照度 | 観測者高度における放射照度 | W/(m²·cm⁻¹) |
| 目標の見かけ放射輝度 | 指定した目標温度と放射率に対し、大気減衰後に経路放射を加えて観測者が見る放射輝度。目標位置での入射放射輝度も同時に出力 | W/(m²·sr·cm⁻¹) |

## 6. 代表的な操作の流れ

### 6.1 単発計算と比較

1. パラメータを設定して「実行」をクリックします。
2. パラメータを 1〜2 つ変更し（例：視程 23 km → 5 km）、再度実行します。新しい結果は同じグラフに別の色で追加され、凡例にシナリオ名が付きます。
3. 右側の曲線パネルで比較したい曲線をオン / オフします。
4. 「結果テーブル」タブで数値を確認します。横軸とスペクトル密度の単位はツールバーの設定に従います。

### 6.2 保存と復元

「ファイル → プロジェクトを保存」で現在のパラメータと全結果を 1 つの JSON ファイルに保存します。次回そのファイルを開くと、再計算なしで曲線が復元されます。

### 6.3 出力

- グラフ：「ファイル → 画像を出力」またはツールバーのボタン。PNG / PDF / JPEG。
- データ：右側の曲線パネルで結果を右クリック →「この結果を CSV に出力」。CSV の横軸単位とスペクトル密度単位はツールバーの現在の設定に従い、ヘッダーに単位が記されます。

### 6.4 目標探知シナリオ

検出器位置での目標の見かけ放射輝度を得るには：

1. 幾何で「斜め経路」を選び、観測者高度・目標高度・天頂角を入力します。
2. 出力項目で「目標の見かけ放射輝度」をオンにし、目標温度と放射率を入力します。
3. 実行すると 4 本の曲線（透過率、経路放射輝度、目標の見かけ放射輝度、目標位置での入射放射輝度）が得られます。
4. 同じ幾何で「天空放射輝度のみ」を計算した背景を目標の見かけ放射輝度から引くと、目標と背景の放射コントラストになります。

## 7. パラメータ掃引とルックアップテーブル

「計算 → パラメータ掃引 / LUT…」は現在のパラメータパネルを基準に、複数パラメータの直積を順に計算してルックアップテーブルを出力します。

### ダイアログの項目

| 項目 | 説明 |
|---|---|
| 掃引の次元 | 1 行につき 1 パラメータ。パラメータは JSON ポインタで記述し、ドロップダウンに主なものが並びます。値はリスト `1, 2, 5, 10` または範囲 `0:10:2`（開始:終了:刻み）。文字列型パラメータは名前を直接書きます（例：`Rural, Urban`） |
| 列名 | 出力ファイル内でのその次元の座標名。既定はパラメータ名 |
| 出力量 | 未選択の場合はシナリオの全量を出力 |
| 帯域平均 | 任意。µm 帯域ごとの帯域平均と帯域積分を併せて書き込みます |
| 出力ファイル | 拡張子で形式が決まります：`.h5` は HDF5、`.csv` は縦長の表 |
| 再開 | 中断後に再実行するとき、完了済みの組み合わせをスキップ |

ダイアログには組み合わせ総数と各組み合わせに必要なカーネル実行回数が表示されます。実行中にキャンセルでき、完了分は保持されます。

### HDF5 ファイル構成

```
/<量名>                       [次元1, …, 次元N, スペクトル]   データ。単位は属性 units
/bands/<量名>_average         [次元1, …, 次元N, 帯域]        帯域平均
/bands/<量名>_integral        [次元1, …, 次元N, 帯域]        帯域積分
/coords/wavenumber            [スペクトル]                   cm⁻¹
/coords/wavelength_um         [スペクトル]                   µm
/coords/<列名>                [値の数]                       各次元の座標（数値または文字列）
/coords/band                  [帯域]                         帯域名
/filled                       [次元1, …, 次元N]              1 = 計算済み
ルート属性：kernel、kernel_version、created_utc、base_scenario（基準シナリオ JSON）、plan（掃引計画 JSON）
```

Python での読み込み（h5py が必要）：

```python
import h5py
with h5py.File("lut.h5") as f:
    T = f["Transmittance"][...]            # 形状 [次元1, …, スペクトル]
    nu = f["coords/wavenumber"][...]
    tgt = f["coords/target_km"][...]
```

インストールフォルダーの `pyqradtran\read_lut_h5.py` は、そのまま使える閲覧スクリプトです。

### CSV 縦長テーブル

1 行が（次元値…、波数、量名、値）。帯域平均は `<ファイル名>.bands.csv` に別途保存されます。Excel のピボットや pandas での読み込みに適しています。

## 8. コマンドラインツール

`qradtran-cli.exe` はインストールフォルダーにあります。「PATH に追加」をオンにしていれば任意の場所から使えます。

```
qradtran-cli example --out case.json         シナリオファイルのテンプレートを生成
qradtran-cli validate case.json              パラメータを検査
qradtran-cli plan case.json                  実行されるカーネル実行を列挙（計算なし）
```

## 11. 計算方法と精度

- **カーネル**：libRadtran 2.0.6 の uvspec を別プロセスとして実行。分子吸収は REPTRAN 代表波長バンドモデル（HITRAN 2004 以降に基づく）、多重散乱は DISORT。
- **斜め経路の透過率**：太陽域は 2 つの高度における直達放射照度の比から、熱赤外域は地表温度を摂動した 2 回の実行の放射輝度差の比から求めます。
- **水平・ほぼ水平な経路**：層の鉛直透過率から消散係数を導き、球面幾何の経路に沿って積分します。
- **経路放射輝度**：観測者位置の放射輝度から、目標位置の放射輝度に透過率を掛けたものを引きます。
- **精度**：長波・中波の大気の窓で MODTRAN4 と比較し、8 例中 6 例で窓領域の帯域平均透過率の差が 0.04 以内、最良で 0.003。強い吸収帯内では 2 世代の分光データに系統的な差があります。詳細は同梱の検証報告を参照してください。
- **REPTRAN の 3 段階**：細 1 cm⁻¹ は MODTRAN の 1 cm⁻¹ バンドモデルと同等クラス。粗 15 cm⁻¹ は迅速な見積もりに適します。

## 12. よくある質問

**起動後、ステータスバーに「カーネルを利用できません」と表示される。**
インストールフォルダーが移動されたか、`kernels\libradtran` がウイルス対策ソフトに削除されています。設定でパスを確認し、必要なら再インストールしてください。

**実行ボタンがグレーアウトしている。**
パラメータパネルの下に赤い検証メッセージが表示されています。指示に従って修正してください。よくある原因：目標高度が観測者と同じなのに斜め経路を選んでいる、天頂角の向きと目標の上下関係が矛盾している、スペクトルの開始と終了が同じ。

**計算が失敗し、ログに「Netcdf error … reptran_…_medium」とある。**
選択した分解能のデータ表がありません。完全版インストーラーには 3 段階すべてが含まれます。縮小版の場合は「粗」を使うかデータを追加してください。

**熱赤外の透過率がすべて 0 になる。**
0.2.0 より前のバージョンで二流ソルバーを選ぶと発生しました。修正済みで、放射輝度が必要な場合は自動的に DISORT を使います。

**計算が遅い。**
細分解能＋広い波長域＋32 ストリームが最も遅くなります。まず粗分解能でパラメータを決め、最後に細分解能で図を作成してください。バッチ計算では同時プロセス数を最大にします。

**グラフ右軸の値の意味がわからない。**
右軸は放射量で、単位はツールバーの「スペクトル密度」（cm⁻¹ あたり、nm あたり、µm あたり）に従います。テーブルと CSV も同じ設定を使います。

**画面が英語で表示される。**
Windows の表示言語が対応リストにない場合、英語にフォールバックします。「ツール → 設定 → 表示言語」で希望の言語を選び、再起動してください。

**Python で「DLL load failed」が出る。**
`PYTHONPATH` は `pyqradtran` サブフォルダーではなく、インストールフォルダー自体（`qradtran_core.dll` と `Qt6Core.dll` がある階層）を指す必要があります。Python は 3.10 64 ビットが必要です。

**自分の libRadtran を使えますか？**
使えます。設定で uvspec.exe とデータディレクトリを自分のバージョンに向けてください。2.0.x である必要があります。

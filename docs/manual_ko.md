# QRadtran 설치 및 사용 설명서

**버전** 0.3.0　　**날짜** 2026-09-19　　**발행** Wuhan WaveFront Co., Ltd.

이 설명서는 简体中文, English, Русский, 日本語, Français, Deutsch, Español 판도 제공됩니다. 설치 후 모든 판은 설치 폴더의 `doc\`에 있습니다.

QRadtran은 적외선 및 광전자 시스템 엔지니어를 위한 대기 투과율 및 복사휘도 계산 소프트웨어입니다. Windows의 그래픽 인터페이스에서 경사 경로와 수평 경로의 분광 투과율, 경로 및 하늘 복사휘도, 표적의 겉보기 복사휘도를 계산합니다. 여러 곡선 비교, 매개변수 스윕을 통한 조회표(CSV / HDF5) 생성, 명령줄 도구, Python 인터페이스를 지원합니다. 계산 커널은 오픈 소스 libRadtran이며 소프트웨어와 함께 설치되므로 별도의 설정이 필요 없습니다.

## 1. 시스템 요구 사항

| 항목 | 요구 사항 |
|---|---|
| 운영 체제 | Windows 10 / 11, 64비트 |
| 프로세서 | 4코어 이상. 커널이 여러 프로세스를 병렬로 실행하므로 코어가 많을수록 일괄 계산이 빠릅니다 |
| 메모리 | 8 GB 이상 |

| 기타 | Python, MSYS2, WSL 불필요. VC++ 런타임 포함 |

Python 인터페이스는 선택 기능이며 시스템에 Python 3.10 64비트와 numpy가 필요합니다.

## 2. 설치

1. `QRadtran-0.3.0-Setup-x64.exe`를 두 번 클릭합니다.
2. 설치 프로그램 언어(简体中文, English, Русский, 日本語, 한국어, Français, Deutsch, Español)를 선택합니다. 선택한 언어는 소프트웨어의 인터페이스 언어로 기록되며 나중에 도구 → 설정에서 바꿀 수 있습니다.
3. 타사 라이선스 안내를 읽고 「다음」을 클릭합니다.
4. 설치 폴더를 선택합니다. 기본값은 `C:\Program Files\QRadtran`입니다. 경로에 한글이 포함되어도 되지만 네트워크 드라이브는 권장하지 않습니다.
5. 추가 작업:
   - **바탕 화면 바로 가기 만들기**: 기본 선택.
   - **설치 폴더를 PATH에 추가**: 기본 선택 해제. 선택하면 아무 명령 프롬프트에서나 `qradtran-cli`를 입력할 수 있습니다.
6. 「설치」를 클릭하고 파일 복사(약 1~3분)를 기다립니다.
7. 완료 페이지에서 소프트웨어를 실행하거나 이 설명서를 열 수 있습니다.

설치 프로그램에는 관리자 권한이 필요합니다. 현재 사용자만을 위해 설치하려면 권한 확인 창에서 「나만 사용하도록 설치」를 선택하십시오. 이때 기본 폴더는 `%LOCALAPPDATA%\Programs\QRadtran`이 됩니다.

### 설치 없이 사용

설치 프로그램을 쓰지 않고 배포 폴더 `QRadtran\` 전체를 원하는 위치에 복사한 뒤 그 안의 `QRadtran.exe`를 직접 실행해도 됩니다. 모든 종속 파일이 폴더 안에 있으므로 폴더를 삭제하면 제거가 완료됩니다.

## 3. 첫 실행

시작 후 창 오른쪽 아래 상태 표시줄을 먼저 확인합니다:

```
커널 libradtran 2.0.6 | 프로세스 7개
```

이 줄이 보이면 계산 커널이 준비된 것입니다. 「프로세스」는 동시에 실행되는 커널 프로세스 수입니다. 「커널을 사용할 수 없음」으로 표시되면 도구 → 설정에서 커널 경로를 확인하십시오(10절 참조).

**인터페이스 언어**: 기본적으로 Windows 표시 언어를 따르며 중국어 간체, 영어, 러시아어, 일본어, 한국어, 프랑스어, 독일어, 스페인어를 지원합니다. 도구 → 설정 → 인터페이스 언어에서 선택하고 다시 시작하면 적용됩니다. 명령줄 인수로 임시 지정할 수도 있습니다(예: `QRadtran.exe --lang ko`).

첫 실행은 사전 설정 시나리오부터 시작하는 것을 권장합니다:

1. 메뉴 파일 → 사전 설정 시나리오 불러오기…에서 `mls_ground_to_air_3_5um.json`(중위도 여름 대기, 지상에서 고도 10 km의 표적을 관측, 3~5 µm)을 선택합니다.
2. 도구 모음의 「실행」을 클릭하거나 F5를 누릅니다.
3. 아래쪽 「작업 및 로그」에 작업 한 줄이 나타나고, 진행률 표시줄이 끝나면 중앙에 곡선이 표시됩니다. 파란색은 투과율(왼쪽 축), 따뜻한 색은 복사량(오른쪽 축)입니다. 전체 과정은 약 7초 걸립니다.

## 5. 매개변수 패널 상세

### 5.1 대기

| 항목 | 설명 |
|---|---|
| 표준 대기 | 열대, 중위도 여름, 중위도 겨울, 아북극 여름, 아북극 겨울, 미국 표준 1976(AFGL 6종 표준 대기) 또는 사용자 정의 프로파일 |
| 프로파일 가져오기 (CSV) | 자체 기압·기온·습도 탐측 자료를 가져옵니다(아래 참조) |
| 수증기 컬럼량 | 선택하면 총 가강수량을 지정한 밀리미터로 조정하고, 선택하지 않으면 표준 대기의 값을 사용합니다 |
| 오존 컬럼량 | 위와 같음, 단위 DU |
| CO₂ 혼합비 | ppm, 기본 420 |

**사용자 정의 프로파일 파일 형식**: CSV 또는 공백으로 구분된 텍스트이며 첫 줄은 열 이름입니다. 필수 열: 고도, 기압, 기온과 습도 열 하나. 인식되는 열 이름(대소문자 무관):

| 양 | 열 이름 | 단위 |
|---|---|---|
| 고도 | z, alt, altitude, height | km(`z_m`이면 미터) |
| 기압 | p, pres, pressure | hPa(`p_pa`이면 Pa) |
| 기온 | t, temp, temperature | K(`t_c`이면 ℃) |
| 습도(택 1) | rh; q; h2o / h2o_vmr | 상대 습도 %; 비습 g/kg; 부피 혼합비 ppmv |
| 오존(선택) | o3, o3_vmr | ppmv |

예:

```
z_km,p_hpa,t_k,rh
0.0,1013.0,295.0,70
1.0,900.0,289.0,65
2.0,795.0,283.0,55
5.0,540.0,262.0,40
10.0,265.0,223.0,20
```

가져온 프로파일 위쪽 고도는 선택한 표준 대기로 보완됩니다.

### 5.2 기하

| 경로 유형 | 의미 | 관련 매개변수 |
|---|---|---|
| 경사 경로(관측자 → 표적) | 관측자와 표적의 고도가 다름 | 관측자 고도, 표적 고도, 관측 천정각 |
| 수평 경로 | 관측자와 표적이 같은 고도 | 관측자 고도, 수평 경로 길이 |
| 전체 층, 수직 | 지표에서 대기 상단까지 | 없음 |
| 하늘 복사휘도만 | 표적 없이 특정 방향의 하늘 복사휘도를 관측 | 관측자 고도, 관측 천정각, 방위각 |

각도 규약:

- **관측 천정각**: 0°는 바로 위, 90°는 수평, 180°는 바로 아래. 표적이 관측자보다 위에 있으면 90° 미만, 아래에 있으면 90° 초과여야 하며, 그렇지 않으면 패널이 오류를 표시합니다.
- **관측 방위각**, **태양 방위각**: 북쪽 0°, 시계 방향.
- **태양 천정각**: 태양 영역의 복사량에만 영향을 주며 투과율에는 영향이 없습니다.
- **지표 해발고도**: 대기 프로파일 바닥의 고도. 관측자와 표적 고도는 모두 해발 고도입니다.

천정각이 85°~95° 사이이면 거의 수평인 경로로 간주하여 층별 소산 적분으로 전환하고 정확도 경고를 표시합니다.

### 5.3 에어로졸 및 구름

| 항목 | 설명 |
|---|---|
| 에어로졸 유형 | 없음, 농촌, 도시, 해양, 대류권(Shettle 모델) 또는 OPAC 혼합 |
| 가시거리 | 지상 수평 가시거리(km). 경계층 에어로졸 농도를 결정합니다 |
| 계절 | 봄/여름 또는 가을/겨울 프로파일 |
| 성층권 에어로졸 | 배경 / 중간 화산성 / 높은 화산성 / 극단적 화산성 |
| OPAC 혼합 이름 | OPAC 선택 시 입력. 예: continental_average, maritime_clean, urban, desert |
| 단일 구름층 | 물구름 또는 얼음구름. 구름 밑면, 윗면, 수분 함량, 유효 반경 지정 |

### 5.4 지표

| 항목 | 설명 |
|---|---|
| 지표 알베도 | 태양 영역용, 0~1 |
| 지표 온도 | 열적외선 영역의 지표 방사 온도 |
| 지표 방사율 | 열적외선 영역용, 0~1 |

### 5.5 스펙트럼

| 항목 | 설명 |
|---|---|
| 스펙트럼 단위 | µm / nm / cm⁻¹. 전환 시 시작/끝 값이 자동 환산됩니다 |
| 시작 / 끝 | 스펙트럼 범위. 태양 영역(≤ 5 µm)과 열적외선 영역(≥ 2.5 µm)을 따로 커널에 맡긴 뒤 결과를 이어 붙입니다 |
| 출력 간격 | 출력 격자 간격. 0이면 커널의 대표 파장 격자를 그대로 사용 |
| 밴드 모델 분해능 | 거침 15 cm⁻¹ / 중간 5 cm⁻¹ / 정밀 1 cm⁻¹ / LOWTRAN 20 cm⁻¹. 정밀할수록 정확하지만 느립니다 |
| 솔버 | DISORT(다중 산란, 기본) 또는 2-스트림. 복사휘도가 필요하면 자동으로 DISORT로 전환됩니다 |
| DISORT 스트림 수 | 기본 16. 산란이 강한 경우(짙은 에어로졸, 구름)에는 32로 늘릴 수 있습니다 |

소요 시간 참고(4코어 사무용 PC): 3~5 µm 지상-공중, 거침 약 7초, 중간 약 30초. 8~12 µm 수평 1 km 약 2초.

### 5.6 출력 항목

| 항목 | 의미 | 단위 |
|---|---|---|
| 경로 투과율 | 관측자에서 표적까지의 분광 투과율 | 무차원 |
| 경로 복사휘도 | 경로상의 대기 자체 방출과 산란이 시선에 들어오는 복사휘도 | W/(m²·sr·cm⁻¹), 전환 가능 |
| 하늘 복사휘도 | 관측자 위치에서 시선 방향으로 보이는 하늘 복사휘도 | 위와 같음 |
| 직달 / 하향 산란 / 상향 복사조도 | 관측자 고도의 복사조도 | W/(m²·cm⁻¹) |
| 표적 겉보기 복사휘도 | 지정한 표적 온도와 방사율에 대해 대기 감쇠 후 경로 복사를 더해 관측자가 보는 복사휘도. 표적 위치의 입사 복사휘도도 함께 출력 | W/(m²·sr·cm⁻¹) |

## 6. 대표적인 작업 흐름

### 6.1 단일 계산과 비교

1. 매개변수를 설정하고 「실행」을 클릭합니다.
2. 매개변수 한두 개를 바꾸고(예: 가시거리 23 km → 5 km) 다시 실행합니다. 새 결과는 같은 그래프에 다른 색으로 추가되며 범례에 시나리오 이름이 붙습니다.
3. 오른쪽 곡선 패널에서 비교할 곡선을 선택/해제합니다.
4. 「결과 표」 탭에서 수치를 확인합니다. 가로축과 스펙트럼 밀도 단위는 도구 모음 설정을 따릅니다.

### 6.2 저장과 복원

파일 → 프로젝트 저장은 현재 매개변수와 모든 결과를 JSON 파일 하나로 저장합니다. 다음에 그 파일을 열면 재계산 없이 곡선이 복원됩니다.

### 6.3 내보내기

- 그래프: 파일 → 이미지 내보내기 또는 도구 모음 버튼. PNG / PDF / JPEG.
- 데이터: 오른쪽 곡선 패널에서 결과를 오른쪽 클릭 → 「이 결과를 CSV로 내보내기」. CSV의 가로축 단위와 스펙트럼 밀도 단위는 도구 모음의 현재 설정을 따르며 헤더에 단위가 표기됩니다.

### 6.4 표적 탐지 시나리오

검출기 위치에서 표적의 겉보기 복사휘도를 얻으려면:

1. 기하에서 「경사 경로」를 선택하고 관측자·표적 고도와 천정각을 입력합니다.
2. 출력 항목에서 「표적 겉보기 복사휘도」를 선택하고 표적 온도와 방사율을 입력합니다.
3. 실행하면 투과율, 경로 복사휘도, 표적 겉보기 복사휘도, 표적 위치 입사 복사휘도의 네 곡선이 나옵니다.
4. 같은 기하로 「하늘 복사휘도만」을 계산한 배경을 표적 겉보기 복사휘도에서 빼면 표적과 배경의 복사 대비가 됩니다.

## 7. 매개변수 스윕과 조회표

계산 → 매개변수 스윕 / LUT…는 현재 매개변수 패널을 기준으로 여러 매개변수의 데카르트 곱을 하나씩 계산하여 조회표를 출력합니다.

### 대화 상자 항목

| 항목 | 설명 |
|---|---|
| 스윕 차원 | 한 줄에 매개변수 하나. 매개변수는 JSON 포인터로 쓰며 드롭다운에 자주 쓰는 항목이 있습니다. 값은 목록 `1, 2, 5, 10` 또는 범위 `0:10:2`(시작:끝:간격). 문자열형 매개변수는 이름을 직접 씁니다(예: `Rural, Urban`) |
| 열 이름 | 출력 파일에서 해당 차원의 좌표 이름. 기본값은 매개변수 이름 |
| 출력량 | 선택하지 않으면 시나리오의 모든 양을 출력 |
| 대역 평균 | 선택 사항. µm 대역별 대역 평균과 대역 적분을 함께 기록 |
| 출력 파일 | 확장자가 형식을 결정: `.h5`는 HDF5, `.csv`는 긴 표 |
| 이어서 실행 | 중단 후 다시 실행할 때 완료된 조합을 건너뜀 |

대화 상자에는 조합 총수와 조합당 필요한 커널 실행 횟수가 표시됩니다. 실행 중 취소할 수 있으며 완료된 부분은 유지됩니다.

### HDF5 파일 구조

```
/<양 이름>                    [차원1, …, 차원N, 스펙트럼]    데이터, 단위는 속성 units
/bands/<양 이름>_average      [차원1, …, 차원N, 대역]        대역 평균
/bands/<양 이름>_integral     [차원1, …, 차원N, 대역]        대역 적분
/coords/wavenumber            [스펙트럼]                    cm⁻¹
/coords/wavelength_um         [스펙트럼]                    µm
/coords/<열 이름>             [값 개수]                     각 차원의 좌표(숫자 또는 문자열)
/coords/band                  [대역]                        대역 이름
/filled                       [차원1, …, 차원N]             1 = 해당 조합 계산 완료
루트 속성: kernel, kernel_version, created_utc, base_scenario(기준 시나리오 JSON), plan(스윕 계획 JSON)
```

Python에서 읽기(h5py 필요):

```python
import h5py
with h5py.File("lut.h5") as f:
    T = f["Transmittance"][...]            # 형상 [차원1, …, 스펙트럼]
    nu = f["coords/wavenumber"][...]
    tgt = f["coords/target_km"][...]
```

설치 폴더의 `pyqradtran\read_lut_h5.py`는 바로 사용할 수 있는 조회 스크립트입니다.

### CSV 긴 표

한 행이 (차원 값…, 파수, 양 이름, 값)입니다. 대역 평균은 `<파일 이름>.bands.csv`에 따로 저장됩니다. Excel 피벗이나 pandas 읽기에 적합합니다.

## 8. 명령줄 도구

`qradtran-cli.exe`는 설치 폴더에 있습니다. 「PATH에 추가」를 선택했다면 어디서나 사용할 수 있습니다.

```
qradtran-cli example --out case.json         시나리오 파일 템플릿 생성
qradtran-cli validate case.json              매개변수 검사
qradtran-cli plan case.json                  실행될 커널 실행 목록 표시(계산 없음)
qradtran-cli run case.json --out out.csv     계산 후 CSV 출력(--unit um|nm|cm-1  --density cm-1|nm|um)
qradtran-cli run case.json --out out.json    JSON 출력(메타데이터 포함)
qradtran-cli batch-example --out plan.json   매개변수 스윕 템플릿 생성
qradtran-cli batch plan.json --out lut.h5    일괄 계산(.h5 또는 .csv, --resume로 이어서 실행)
qradtran-cli kernel-info                     커널 상태와 사용 가능한 분해능 표시
```

종료 코드: 0 성공, 1 인수 오류, 2 검증 실패, 3 커널 실패. 시나리오 파일과 GUI 프로젝트 파일은 서로 호환됩니다.

## 9. Python 인터페이스

설치 폴더의 `pyqradtran\`은 Python 3.10 64비트용으로 빌드된 Python 패키지입니다. 사용 전에 설치 폴더를 `PYTHONPATH`에 추가합니다:

```bat
set PYTHONPATH=C:\Program Files\QRadtran
python
```

```python
import pyqradtran as qr

s = qr.Scenario.standard("MidlatitudeSummer")
s.geometry.mode = "SlantPath"
s.geometry.observer_alt_km = 0.0
s.geometry.target_alt_km = 10.0
s.geometry.view_zenith_deg = 30.0
s.aerosol.type = "Rural"
s.aerosol.visibility_km = 23.0
s.spectral.set_range(3, 5, unit="Micrometer", step=0.01, resolution="Coarse")
s.outputs.transmittance = True
s.outputs.path_radiance = True

r = qr.run(s)
nu = r.wavenumber                   # numpy 배열, cm⁻¹
T = r["Transmittance"]
L = r.series("PathRadiance", per="Micrometer")     # µm당으로 환산
print(r.band_average("Transmittance", 3.0, 5.0))  # {'average':…, 'integral':…}
r.to_csv("out.csv", unit="Micrometer")

# 매개변수 스윕
plan = qr.BatchPlan()
plan.base = s
plan.add_dimension("/geometry/target_alt_km", [1, 2, 5, 10], "tgt_km")
plan.add_band("MWIR", 3.0, 5.0)
qr.batch(plan, "lut.h5")
```

전체 예제는 `pyqradtran\python_quickstart.py`에 있습니다. 바인딩은 GUI와 같은 코어 라이브러리와 커널을 사용하므로 결과가 완전히 일치합니다.

## 11. 계산 방법과 정확도

- **커널**: libRadtran 2.0.6의 uvspec을 별도 프로세스로 호출. 분자 흡수는 REPTRAN 대표 파장 밴드 모델(HITRAN 2004 및 이후 기반), 다중 산란은 DISORT.
- **경사 경로 투과율**: 태양 영역은 두 고도의 직달 복사조도 비로, 열적외선 영역은 지표 온도를 교란한 두 실행의 복사휘도 차 비로 구합니다.
- **수평 및 거의 수평인 경로**: 해당 층의 수직 투과율에서 소산 계수를 유도한 뒤 구면 기하 경로를 따라 적분합니다.
- **경로 복사휘도**: 관측자 위치의 복사휘도에서 표적 위치의 복사휘도에 투과율을 곱한 값을 뺍니다.
- **정확도**: 장파 및 중파 대기 창에서 MODTRAN4와 비교하여 8개 사례 중 6개에서 창 영역 대역 평균 투과율 편차가 0.04 이내, 최상은 0.003. 강한 흡수 대역 안에서는 두 세대의 분광 데이터에 계통적 차이가 있습니다. 자세한 내용은 소프트웨어에 포함된 검증 보고서를 참조하십시오.
- **REPTRAN 세 단계**: 정밀 1 cm⁻¹은 MODTRAN의 1 cm⁻¹ 밴드 모델과 같은 급이며, 거침 15 cm⁻¹은 빠른 추정에 적합합니다.

## 12. 자주 묻는 질문

**시작 후 상태 표시줄에 「커널을 사용할 수 없음」이 표시됩니다.**
설치 폴더가 이동되었거나 `kernels\libradtran`이 백신 프로그램에 의해 삭제되었습니다. 설정에서 경로를 확인하고 필요하면 다시 설치하십시오.

**실행 버튼이 회색입니다.**
매개변수 패널 아래에 빨간 검증 메시지가 있습니다. 안내에 따라 수정하십시오. 흔한 원인: 표적 고도가 관측자와 같은데 경사 경로를 선택함, 천정각 방향과 표적의 위아래 관계가 모순됨, 스펙트럼 시작과 끝이 같음.

**계산이 실패하고 로그에 「Netcdf error … reptran_…_medium」이 있습니다.**
선택한 분해능의 데이터 표가 없습니다. 전체 설치 패키지에는 세 단계가 모두 포함됩니다. 축소판을 사용 중이면 「거침」 분해능을 쓰거나 데이터를 추가하십시오.

**열적외선 투과율이 모두 0입니다.**
0.2.0 이전 버전에서 2-스트림 솔버를 선택하면 발생했으며 수정되었습니다. 복사휘도가 필요하면 자동으로 DISORT를 사용합니다.

**계산이 느립니다.**
정밀 분해능 + 넓은 파장 대역 + 32 스트림이 가장 느립니다. 먼저 거침 분해능으로 매개변수를 정한 뒤 마지막에 정밀 분해능으로 그림을 만드십시오. 일괄 계산에서는 동시 프로세스를 최대로 하십시오.

**그래프 오른쪽 축의 값이 이해되지 않습니다.**
오른쪽 축은 복사량이며 단위는 도구 모음의 「스펙트럼 밀도」(cm⁻¹당, nm당, µm당)를 따릅니다. 표와 CSV도 같은 설정을 씁니다.

**화면이 영어로 표시됩니다.**
Windows 표시 언어가 지원 목록에 없으면 영어로 돌아갑니다. 도구 → 설정 → 인터페이스 언어에서 원하는 언어를 선택하고 다시 시작하십시오.

**Python에서 「DLL load failed」가 발생합니다.**
`PYTHONPATH`는 `pyqradtran` 하위 폴더가 아니라 설치 폴더 자체(`qradtran_core.dll`과 `Qt6Core.dll`이 있는 계층)를 가리켜야 합니다. Python은 3.10 64비트여야 합니다.

**자체 libRadtran을 사용할 수 있습니까?**
가능합니다. 설정에서 uvspec.exe와 데이터 디렉터리를 자체 버전으로 지정하십시오. 2.0.x여야 합니다.

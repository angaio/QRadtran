QRadtran — руководство по установке и использованию

Версия 0.3.0　　Дата 2026-09-19　　Издатель Wuhan WaveFront Co., Ltd.

Руководство также доступно на языках 简体中文, English, 日本語, 한국어, Français, Deutsch и Español; после установки все версии находятся в папке doc\ каталога установки.

QRadtran — программа расчёта пропускания и излучения атмосферы для инженеров инфракрасных и оптико-электронных систем. В Windows она через графический интерфейс вычисляет спектральное пропускание наклонных и горизонтальных трасс, яркость трассы и неба, а также видимую яркость цели. Поддерживаются сравнение нескольких кривых, перебор параметров с созданием таблиц (CSV / HDF5), инструмент командной строки и интерфейс Python. Расчётным ядром служит открытая программа libRadtran, устанавливаемая вместе с ПО; дополнительная настройка не требуется.

1. Системные требования

Параметр Требование
Операционная система Windows 10 / 11, 64-разрядная
Процессор 4 ядра и более. Ядро запускает несколько процессов параллельно; чем больше ядер, тем быстрее пакетные расчёты
Память 8 ГБ и более
Диск Около 1,2 ГБ после установки (включая спектральные таблицы всех трёх разрешений). Рекомендуется SSD: расчёты с тонким разрешением читают много данных
Экран 1600 × 900 и больше
Прочее Python, MSYS2 и WSL не требуются; среда выполнения VC++ включена

Интерфейс Python необязателен и требует системного Python 3.10 64-бит с numpy.

2. Установка

  1. Дважды щёлкните QRadtran-0.3.0-Setup-x64.exe.
  2. Выберите язык установщика (简体中文, English, Русский, 日本語, 한국어, Français, Deutsch, Español). Установщик запоминает выбранный язык как язык интерфейса программы; позже его можно изменить в меню Инструменты → Настройки.
  3. Прочитайте сведения о лицензиях сторонних компонентов и нажмите «Далее».
  4. Выберите папку установки, по умолчанию C:\Program Files\QRadtran. Путь может содержать не только латинские символы, но сетевой диск не рекомендуется.
  5. Дополнительные задачи:
  6. Создать ярлык на рабочем столе: включено по умолчанию.
  7. Добавить папку установки в PATH: по умолчанию выключено. Если включить, qradtran-cli можно вызывать из любой командной строки.
  8. Нажмите «Установить» и дождитесь копирования файлов (1–3 минуты).
  9. На последней странице можно запустить программу или открыть это руководство.

Установщику нужны права администратора. Чтобы установить только для текущего пользователя, выберите «Установить только для меня» в запросе прав; папкой по умолчанию тогда станет %LOCALAPPDATA%\Programs\QRadtran.

Переносной вариант

Установщик необязателен: скопируйте всю папку дистрибутива QRadtran\ в любое место и запускайте из неё QRadtran.exe. Все зависимости находятся внутри папки; удаление папки удаляет программу.

3. Первый запуск

После запуска посмотрите на строку состояния в правом нижнем углу окна:

Ядро libradtran 2.0.6 | процессов: 7

Эта строка означает, что расчётное ядро готово; «процессов» — число одновременно работающих процессов ядра. Если написано «Ядро недоступно», откройте Инструменты → Настройки и проверьте путь к ядру, см. раздел 10.

Язык интерфейса: по умолчанию программа следует языку отображения Windows и поддерживает упрощённый китайский, английский, русский, японский, корейский, французский, немецкий и испанский. Выберите язык в меню Инструменты → Настройки → Язык интерфейса и перезапустите программу; язык можно также задать в командной строке, например QRadtran.exe --lang ru.

Для первого запуска начните с готового сценария:

  1. Меню Файл → Загрузить готовый сценарий…, выберите mls_ground_to_air_3_5um.json (атмосфера средних широт летом, наблюдение с земли цели на высоте 10 км, 3–5 мкм).
  2. Нажмите «Запуск» на панели инструментов или F5.
  3. В панели «Задачи и журнал» внизу появится задача; когда индикатор выполнения дойдёт до конца, в центре появятся кривые: синяя — пропускание (левая ось), тёплые цвета — энергетические величины (правая ось). Весь расчёт занимает около 7 секунд.

5. Панель параметров подробно

5.1 Атмосфера

Параметр Описание
Стандартная атмосфера Тропики, средние широты лето, средние широты зима, субарктика лето, субарктика зима, стандарт США 1976 (шесть атмосфер AFGL) или пользовательский профиль
Импорт профиля (CSV) Импорт собственного зондирования давления/температуры/влажности, см. ниже
Столб водяного пара Если включено, общая осаждаемая вода масштабируется до заданных миллиметров; иначе используется значение стандартной атмосферы
Столб озона Аналогично, в DU
Отношение смеси CO₂ ppm, по умолчанию 420

Формат файла пользовательского профиля: CSV или текст с разделителями-пробелами и строкой заголовка. Обязательные столбцы: высота, давление, температура и один столбец влажности. Распознаваемые имена столбцов (без учёта регистра):

Величина Имена столбцов Единица
Высота z, alt, altitude, height км (z_m — метры)
Давление p, pres, pressure гПа (p_pa — Па)
Температура t, temp, temperature К (t_c — °C)
Влажность (одно из) rh; q; h2o / h2o_vmr относительная влажность %; удельная влажность г/кг; объёмное отношение смеси ppmv
Озон (необязательно) o3, o3_vmr ppmv

Пример:

z_km,p_hpa,t_k,rh
0.0,1013.0,295.0,70
1.0,900.0,289.0,65
2.0,795.0,283.0,55
5.0,540.0,262.0,40
10.0,265.0,223.0,20

Выше импортированного профиля уровни дополняются выбранной стандартной атмосферой.

5.2 Геометрия

Тип трассы Смысл Параметры
Наклонная трасса (наблюдатель → цель) Наблюдатель и цель на разных высотах Высота наблюдателя, высота цели, зенитный угол наблюдения
Горизонтальная трасса Наблюдатель и цель на одной высоте Высота наблюдателя, длина горизонтальной трассы
Вся толща, вертикально От поверхности до верхней границы атмосферы Нет
Только яркость неба Без цели; яркость неба в заданном направлении Высота наблюдателя, зенитный угол, азимут

Соглашения об углах:

  • Зенитный угол наблюдения: 0° — вертикально вверх, 90° — горизонтально, 180° — вертикально вниз. Он должен быть меньше 90°, если цель выше наблюдателя, и больше 90° в противном случае; иначе панель сообщит об ошибке.
  • Азимут наблюдения, азимут Солнца: 0° — север, по часовой стрелке.
  • Зенитный угол Солнца: влияет только на энергетические величины солнечного диапазона, не на пропускание.
  • Высота поверхности: высота нижней границы профиля атмосферы; высоты наблюдателя и цели отсчитываются от уровня моря.

При зенитных углах от 85° до 95° программа переходит к послойному интегрированию ослабления для почти горизонтальных трасс и выдаёт предупреждение о точности.

Параметр Описание

Видимость Горизонтальная видимость у поверхности, км; задаёт содержание аэрозоля в пограничном слое
Сезон Профиль весна/лето или осень/зима

Один слой облаков Водяное или ледяное облако с нижней и верхней границей, водностью и эффективным радиусом

5.4 Поверхность

Параметр Описание
Альбедо поверхности Солнечный диапазон, от 0 до 1
Температура поверхности Температура излучения поверхности в тепловом ИК
Излучательная способность поверхности Тепловой ИК, от 0 до 1

5.5 Спектр

Параметр Описание
Спектральная единица мкм / нм / см⁻¹. При смене единицы границы пересчитываются
От / до Спектральный диапазон. Программа передаёт ядру солнечный (≤ 5 мкм) и тепловой (≥ 2,5 мкм) диапазоны отдельно и объединяет результаты
Шаг вывода Шаг выходной сетки; 0 — использовать сетку представительных длин волн ядра
Разрешение полосной модели Грубое 15 см⁻¹ / среднее 5 см⁻¹ / тонкое 1 см⁻¹ / LOWTRAN 20 см⁻¹. Тоньше — точнее и медленнее
Решатель DISORT (многократное рассеяние, по умолчанию) или двухпотоковый. Когда нужна яркость, программа автоматически переходит на DISORT
Число потоков DISORT По умолчанию 16; для сильно рассеивающих случаев (плотный аэрозоль, облака) увеличьте до 32

Ориентировочное время (4-ядерный офисный ПК): 3–5 мкм земля–воздух, грубое разрешение около 7 с, среднее около 30 с; 8–12 мкм горизонтально 1 км около 2 с.

5.6 Выходные величины

Параметр Смысл Единица
Пропускание трассы Спектральное пропускание от наблюдателя к цели безразмерное
Яркость трассы Яркость, излучённая и рассеянная атмосферой в направление визирования вдоль трассы Вт/(м²·ср·см⁻¹), переключается
Яркость неба Яркость неба, видимая наблюдателем вдоль линии визирования как выше
Прямая / рассеянная нисходящая / восходящая облучённость Облучённости на высоте наблюдателя Вт/(м²·см⁻¹)
Видимая яркость цели При заданных температуре и излучательной способности цели — яркость, видимая наблюдателем после ослабления атмосферой плюс яркость трассы; также выводится падающая яркость у цели Вт/(м²·ср·см⁻¹)

6. Типовые сценарии работы

6.1 Одиночный расчёт и сравнение

  1. Задайте параметры и нажмите «Запуск».
  2. Измените один-два параметра (например, видимость с 23 км на 5 км) и запустите снова. Новый результат добавится на тот же график другим цветом с именем сценария в легенде.
  3. Включайте и выключайте кривые в панели «Кривые» справа для сравнения.
  4. Перейдите на вкладку «Таблица результатов», чтобы увидеть числа; единицы оси и спектральной плотности следуют панели инструментов.

6.2 Сохранение и восстановление

Файл → Сохранить проект записывает текущие параметры и все результаты в один файл JSON. При последующем открытии кривые восстанавливаются без пересчёта.

6.3 Экспорт

  • График: Файл → Экспорт изображения или кнопка на панели, PNG / PDF / JPEG.
  • Данные: правый щелчок по результату в панели «Кривые» → «Экспортировать этот результат в CSV». В CSV используются единицы оси и спектральной плотности, выбранные на панели инструментов; единицы указаны в заголовке.

6.4 Сценарий обнаружения цели

Чтобы получить видимую яркость цели на приёмнике:

  1. В геометрии выберите «Наклонная трасса», введите высоты наблюдателя и цели и зенитный угол.
  2. В выходных величинах включите «Видимая яркость цели», введите температуру и излучательную способность цели.
  3. После расчёта получаются четыре кривые: пропускание, яркость трассы, видимая яркость цели и падающая яркость у цели.
  4. Вычтите из видимой яркости цели результат «Только яркость неба» для той же геометрии — получится радиационный контраст цели и фона.

7. Перебор параметров и таблицы

Расчёт → Перебор параметров / таблица… берёт за основу текущую панель параметров, рассчитывает каждую комбинацию (декартово произведение) выбранных значений и записывает таблицу.

Элементы диалога

Элемент Описание
Измерения перебора Один параметр в строке. Параметры записываются как указатели JSON; в списке приведены распространённые. Значения — список 1, 2, 5, 10 или диапазон 0:10:2 (начало:конец:шаг); строковые параметры записываются по имени, например Rural, Urban
Столбец Имя координаты этого измерения в выходном файле, по умолчанию имя параметра
Выходные величины Если ничего не выбрано, записываются все величины сценария
Средние по полосам Необязательно; среднее и интеграл по полосам в мкм записываются рядом
Выходной файл Расширение задаёт формат: .h5 — HDF5, .csv — длинная таблица
Продолжить При повторном запуске после прерывания пропускает уже рассчитанные комбинации

Диалог показывает общее число комбинаций и число запусков ядра на комбинацию. Расчёт можно отменить; выполненная часть сохраняется.

Структура файла HDF5

/<Величина>                   [изм1, …, измN, спектр]     данные, единица в атрибуте "units"
/bands/<Величина>_average     [изм1, …, измN, полоса]     среднее по полосе
/bands/<Величина>_integral    [изм1, …, измN, полоса]     интеграл по полосе
/coords/wavenumber            [спектр]                    см⁻¹
/coords/wavelength_um         [спектр]                    мкм
/coords/<столбец>             [значения]                  координата каждого измерения (число или строка)
/coords/band                  [полоса]                    имена полос
/filled                       [изм1, …, измN]             1 = комбинация рассчитана
Атрибуты корня: kernel, kernel_version, created_utc, base_scenario (JSON базового сценария), plan (JSON плана перебора)

Чтение в Python (нужен h5py):

import h5py
with h5py.File("lut.h5") as f:
    T = f["Transmittance"][...]            # форма [изм1, …, спектр]
    nu = f["coords/wavenumber"][...]
    tgt = f["coords/target_km"][...]

pyqradtran\read_lut_h5.py в папке установки — готовый скрипт просмотра.

Длинная таблица CSV

Одна строка на (значения измерений…, волновое число, величина, значение); средние по полосам записываются в <файл>.bands.csv. Подходит для сводных таблиц Excel и pandas.

8. Инструмент командной строки

qradtran-cli.exe находится в папке установки; при включённом «Добавить в PATH» работает из любого места.

qradtran-cli example --out case.json         создать шаблон файла сценария
qradtran-cli validate case.json              проверить параметры
qradtran-cli plan case.json                  перечислить запуски ядра без расчёта
qradtran-cli run case.json --out out.csv     рассчитать и записать CSV (--unit um|nm|cm-1  --density cm-1|nm|um)
qradtran-cli run case.json --out out.json    записать JSON (с метаданными)
qradtran-cli batch-example --out plan.json   создать шаблон плана перебора
qradtran-cli batch plan.json --out lut.h5    пакетный расчёт (.h5 или .csv; --resume для продолжения)
qradtran-cli kernel-info                     показать состояние ядра и доступные разрешения

Коды выхода: 0 — успех, 1 — ошибка аргументов, 2 — ошибка проверки, 3 — ошибка ядра. Файлы сценариев и файлы проектов GUI взаимозаменяемы.

9. Интерфейс Python

pyqradtran\ в папке установки — пакет Python, собранный для Python 3.10 64-бит. Перед использованием добавьте папку установки в PYTHONPATH:

set PYTHONPATH=C:\Program Files\QRadtran
python

import pyqradtran as qr

s = qr.Scenario.standard("MidlatitudeSummer")
s.geometry.mode = "SlantPath"
s.geometry.observer_alt_km = 0.0
s.geometry.target_alt_km = 10.0
s.geometry.view_zenith_deg = 30.0
s.aerosol.type = "Rural"
s.aerosol.visibility_km = 23.0
s.spectral.set_range(3, 5, unit="Micrometer", step=0.01, resolution="Coarse")
s.outputs.transmittance = True
s.outputs.path_radiance = True

r = qr.run(s)
nu = r.wavenumber                   # массив numpy, см⁻¹
T = r["Transmittance"]
L = r.series("PathRadiance", per="Micrometer")     # пересчёт на мкм
print(r.band_average("Transmittance", 3.0, 5.0))  # {'average':…, 'integral':…}
r.to_csv("out.csv", unit="Micrometer")

# перебор параметров
plan = qr.BatchPlan()
plan.base = s
plan.add_dimension("/geometry/target_alt_km", [1, 2, 5, 10], "tgt_km")
plan.add_band("MWIR", 3.0, 5.0)
qr.batch(plan, "lut.h5")

Полный пример — pyqradtran\python_quickstart.py. Привязки используют ту же основную библиотеку и ядро, что и GUI, поэтому результаты полностью совпадают.

11. Метод расчёта и точность

  • Ядро: uvspec из libRadtran 2.0.6, запускается отдельным процессом; молекулярное поглощение — полосная модель представительных длин волн REPTRAN (на основе HITRAN 2004 и позднее), многократное рассеяние — DISORT.
  • Пропускание наклонной трассы: в солнечном диапазоне — отношение прямых облучённостей на двух высотах; в тепловом — отношение разностей яркостей двух запусков с возмущённой температурой поверхности.
  • Горизонтальные и почти горизонтальные трассы: коэффициент ослабления выводится из вертикального пропускания слоя и интегрируется вдоль сферической трассы.
  • Яркость трассы: яркость у наблюдателя минус яркость у цели, умноженная на пропускание.
  • Точность: сверка с MODTRAN4 в длинноволновом и средневолновом окнах прозрачности; в 6 из 8 случаев средняя по полосе оконная пропускаемость отличается менее чем на 0,04, в лучшем случае на 0,003. Внутри сильных полос поглощения два поколения спектроскопических данных различаются систематически. См. отчёт о верификации в составе программы.
  • Разрешения REPTRAN: тонкое 1 см⁻¹ того же класса, что полосная модель MODTRAN 1 см⁻¹; грубое 15 см⁻¹ подходит для быстрых оценок.

12. Часто задаваемые вопросы

После запуска в строке состояния «Ядро недоступно». Папка установки была перемещена или антивирус удалил kernels\libradtran. Проверьте пути в настройках; при необходимости переустановите.

Кнопка «Запуск» неактивна. Под панелью параметров показано красное сообщение проверки; исправьте указанное. Частые причины: выбрана наклонная трасса при равных высотах цели и наблюдателя; зенитный угол противоречит положению цели выше/ниже; одинаковые границы спектра.

Расчёт завершается ошибкой, в журнале «Netcdf error … reptran_…_medium». Отсутствуют таблицы данных выбранного разрешения. Полный установщик содержит все три; в сокращённом пакете используйте «Грубое» или добавьте данные.

Пропускание в тепловом ИК всюду равно нулю. Встречалось в версиях до 0.2.0 с двухпотоковым решателем; исправлено — при необходимости яркости автоматически используется DISORT.

Расчёт идёт медленно. Самое медленное — тонкое разрешение с широким диапазоном и 32 потоками. Подберите параметры на грубом разрешении, а итоговый график стройте на тонком; в пакетных расчётах используйте все доступные процессы.

Непонятны значения на правой оси. Правая ось показывает энергетические величины; единица следует настройке «Спектральная плотность» на панели инструментов: на см⁻¹, на нм или на мкм. Таблицы и CSV используют ту же настройку.

Интерфейс на английском. Если язык отображения Windows не входит в поддерживаемые, программа переключается на английский. Выберите язык в меню Инструменты → Настройки → Язык интерфейса и перезапустите программу.

Python сообщает «DLL load failed». PYTHONPATH должен указывать на саму папку установки (уровень с qradtran_core.dll и Qt6Core.dll), а не на подпапку pyqradtran; Python должен быть 3.10 64-бит.

Можно ли использовать свой libRadtran? Да. Укажите в настройках uvspec.exe и каталог данных своей версии; она должна быть 2.0.x.

13. Удаление

Удалите QRadtran через Параметры → Приложения или запустите «Удалить QRadtran» из меню «Пуск». При удалении сохраняются файлы проектов пользователя и записи запусков в %LOCALAPPDATA%\WaveFront\QRadtran; при необходимости удалите их вручную.

Переносной вариант удаляется простым удалением папки.

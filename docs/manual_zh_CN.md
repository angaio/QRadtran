# QRadtran 安装使用说明

**版本** 0.3.0　　**日期** 2026-09-19　　**发布方** Wuhan WaveFront Co., Ltd.

本说明另有 English / Русский / 日本語 / 한국어 / Français / Deutsch / Español 版本，安装后位于安装目录 `doc\` 下。

QRadtran 是面向红外与光电系统工程师的大气透过率与辐射计算软件。它在 Windows 上以图形界面完成斜程与水平路径透过率、路径与天空辐射亮度、目标表观辐射亮度的光谱计算，支持多曲线对比、参数扫描生成查找表（CSV / HDF5）、命令行与 Python 调用。计算内核为开源的 libRadtran，随软件一起安装，无需另行配置。

## 1. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，64 位 |
| 处理器 | 4 核以上。计算内核可多进程并行，核数越多批量计算越快 |
| 内存 | 8 GB 以上 |
| 磁盘 | 安装后约 1.2 GB（含全部三档分辨率的光谱参数表）；建议安装到固态硬盘，细分辨率计算读盘量大 |
| 显示 | 1600 × 900 以上分辨率 |
| 其他 | 无需安装 Python、MSYS2 或 WSL；VC++ 运行库已内置 |

Python 接口是可选功能，需要本机自带 Python 3.10 64 位及 numpy。

## 2. 安装

1. 双击 `QRadtran-0.3.0-Setup-x64.exe`。
2. 选择安装程序语言（简体中文、English、Русский、日本語、한국어、Français、Deutsch、Español）。安装程序会把所选语言记为软件的界面语言，之后可在「工具 → 设置」中更改。
3. 阅读第三方组件许可说明，点击「下一步」。
4. 选择安装目录，默认 `C:\Program Files\QRadtran`。目录路径可以含中文，但不建议放在网络盘上。
5. 附加任务：
   - **创建桌面快捷方式**：默认勾选。
   - **将安装目录加入 PATH**：默认不勾选。勾选后可在任意命令行窗口直接输入 `qradtran-cli`。
6. 点击「安装」，等待复制文件（约 1 至 3 分钟）。
7. 完成页可直接运行软件或打开本说明。

安装程序需要管理员权限。如果只想为当前用户安装，可在权限提示中选择「仅为我安装」，此时默认目录变为 `%LOCALAPPDATA%\Programs\QRadtran`。

### 免安装方式

也可以不用安装程序：把发布目录 `QRadtran\` 整个复制到任意位置，直接运行其中的 `QRadtran.exe`。所有依赖都在目录内，删除目录即完成卸载。

## 3. 首次运行

启动后先看窗口右下角状态栏：

```
内核 libradtran 2.0.6 | 并发 7
```

出现这一行表示计算内核已就绪，「并发」是同时运行的内核进程数。如果显示「内核不可用」，请打开「工具 → 设置」检查内核路径，见第 10 节。

**界面语言**：软件默认跟随 Windows 显示语言，支持简体中文、英文、俄文、日文、韩文、法文、德文、西班牙文。在「工具 → 设置 → 界面语言」中选择后重新启动生效；也可用命令行参数临时指定，如 `QRadtran.exe --lang en`。

建议第一次运行从预设场景开始：

1. 菜单「文件 → 加载预设场景…」，选择 `mls_ground_to_air_3_5um.json`（中纬度夏季大气，地面看向 10 km 高度的目标，3–5 µm）。
2. 点击工具栏「运行」或按 F5。
3. 底部「任务与日志」出现一行任务，进度条走完后中央区域显示曲线：蓝色为透过率（左轴），暖色为辐射量（右轴）。整个过程约 7 秒。

## 5. 参数面板详解

### 5.1 大气

| 项目 | 说明 |
|---|---|
| 标准大气 | 热带、中纬度夏、中纬度冬、亚北极夏、亚北极冬、美国标准 1976，即 AFGL 六种标准大气；或「自定义廓线」 |
| 导入廓线 (CSV) | 导入自己的温压湿探空数据，见下 |
| 水汽柱含量 | 勾选后把整层可降水量缩放到指定毫米数，不勾选则用标准大气自带值 |
| 臭氧柱含量 | 同上，单位 DU |
| CO₂ 混合比 | ppm，默认 420 |

**自定义廓线文件格式**：CSV 或空白分隔的文本，第一行为列名。必需列：高度、气压、温度，以及一个湿度列。识别的列名（不区分大小写）：

| 量 | 可用列名 | 单位 |
|---|---|---|
| 高度 | z, alt, altitude, height | km（列名写 `z_m` 则按米） |
| 气压 | p, pres, pressure | hPa（`p_pa` 则按 Pa） |
| 温度 | t, temp, temperature | K（`t_c` 则按 ℃） |
| 湿度（三选一） | rh；q；h2o / h2o_vmr | 相对湿度 %；比湿 g/kg；体积混合比 ppmv |
| 臭氧（可选） | o3, o3_vmr | ppmv |

示例：

```
z_km,p_hpa,t_k,rh
0.0,1013.0,295.0,70
1.0,900.0,289.0,65
2.0,795.0,283.0,55
5.0,540.0,262.0,40
10.0,265.0,223.0,20
```

导入后廓线之上的高度由所选标准大气补全。

### 5.2 几何

| 路径类型 | 含义 | 相关参数 |
|---|---|---|
| 斜程（观测者→目标） | 观测者与目标高度不同 | 观测者高度、目标高度、观测天顶角 |
| 水平路径 | 观测者与目标同高度 | 观测者高度、水平路径长度 |
| 整层垂直 | 地表到大气顶 | 无 |
| 仅天空辐射 | 不设目标，看天空某方向的辐射亮度 | 观测者高度、观测天顶角、方位角 |

角度约定：

- **观测天顶角**：0° 为正上方，90° 水平，180° 正下方。目标在观测者上方时须小于 90°，反之须大于 90°，否则面板会提示错误。
- **观测方位角**、**太阳方位角**：北为 0°，顺时针。
- **太阳天顶角**：只影响太阳波段的辐射量，对透过率无影响。
- **地表海拔**：整个大气廓线的底部高度，观测者与目标高度均为海拔。

天顶角在 85° 至 95° 之间时软件改用分层消光积分处理近水平路径，并给出精度警告。

### 5.3 气溶胶与云

| 项目 | 说明 |
|---|---|
| 气溶胶类型 | 无、乡村、城市、海洋、对流层（Shettle 模型），或 OPAC 组分 |
| 能见度 | 地面水平能见度，km，决定边界层气溶胶浓度 |
| 季节 | 春夏 / 秋冬廓线 |
| 平流层气溶胶 | 背景 / 中等火山 / 高火山 / 极端火山 |
| OPAC 混合名称 | 选 OPAC 时填写，如 continental_average、maritime_clean、urban、desert |
| 单层云 | 水云或冰云，给云底、云顶、含水量、有效半径 |

### 5.4 地表

| 项目 | 说明 |
|---|---|
| 地表反照率 | 太阳波段用，0 至 1 |
| 地表温度 | 热红外波段的地表发射温度 |
| 地表发射率 | 热红外波段用，0 至 1 |

### 5.5 光谱

| 项目 | 说明 |
|---|---|
| 光谱单位 | µm / nm / cm⁻¹。切换时起止值自动换算 |
| 起始 / 终止 | 光谱范围。软件自动把太阳波段（≤ 5 µm）和热红外波段（≥ 2.5 µm）分别交给内核计算再拼接 |
| 输出步长 | 输出网格间隔；填 0 表示直接用内核的代表波长网格 |
| 带模式分辨率 | 粗 15 cm⁻¹ / 中 5 cm⁻¹ / 细 1 cm⁻¹ / LOWTRAN 20 cm⁻¹。越细越准也越慢 |
| 求解器 | DISORT（多次散射，默认）或两流近似。需要辐射亮度时软件会自动改用 DISORT |
| DISORT 流数 | 默认 16；散射强的场景（厚气溶胶、云）可增到 32 |

耗时参考（4 核办公机）：3–5 µm 地对空，粗分辨率约 7 秒，中分辨率约 30 秒；8–12 µm 水平 1 km 约 2 秒。

### 5.6 输出项

| 项目 | 含义 | 单位 |
|---|---|---|
| 路径透过率 | 观测者到目标的光谱透过率 | 无量纲 |
| 路径辐射亮度 | 路径上大气自身发射与散射进入视线的辐射亮度 | W/(m²·sr·cm⁻¹)，可切换 |
| 天空辐射亮度 | 观测者处沿视线看到的天空辐射亮度 | 同上 |
| 直射辐照度 / 下行漫射辐照度 / 上行辐照度 | 观测者高度处的辐照度 | W/(m²·cm⁻¹) |
| 目标表观辐射亮度 | 给定目标温度与发射率，经大气衰减并加上路径辐射后观测者看到的辐射亮度；同时输出目标处的入射辐射亮度 | W/(m²·sr·cm⁻¹) |

## 6. 典型操作流程

### 6.1 单次计算与对比

1. 设置参数，点击「运行」。
2. 修改一两个参数（例如能见度从 23 km 改为 5 km），再次运行。新结果以不同颜色追加到同一张图，图例中带场景名。
3. 在右侧曲线面板勾选 / 取消要对比的曲线。
4. 切换到「结果表格」标签查看数值；横轴与谱密度单位随工具栏切换。

### 6.2 保存与恢复

「文件 → 保存工程」把当前参数和全部结果存为一个 JSON 文件。下次打开该文件，曲线会直接恢复，无需重算。

### 6.3 导出

- 曲线图：「文件 → 导出图片」或工具栏按钮，PNG / PDF / JPEG。
- 数据：右侧曲线面板中右键某个结果 → 「导出该结果为 CSV」。CSV 的横轴单位和谱密度单位跟随工具栏当前设置，文件头注明单位。

### 6.4 目标探测场景

要得到目标在探测器处的表观辐射亮度：

1. 几何选「斜程」，填观测者与目标高度、天顶角。
2. 输出项勾选「目标表观辐射亮度」，填目标温度与发射率。
3. 运行后得到四条曲线：透过率、路径辐射亮度、目标表观辐射亮度、目标处入射辐射亮度。
4. 把目标表观辐射亮度减去同几何下「仅天空辐射」得到的背景，即为目标与背景的辐射对比度。

## 7. 参数扫描与查找表

「计算 → 参数扫描 / LUT…」以当前参数面板为基准，对若干参数取笛卡尔积逐一计算，输出查找表。

### 对话框各项

| 项目 | 说明 |
|---|---|
| 扫描维度 | 每行一个参数。参数用 JSON 指针写，下拉框列出常用项；取值可写列表 `1, 2, 5, 10` 或范围 `0:10:2`（起:止:步长）；字符串型参数直接写名字，如 `Rural, Urban` |
| 列名 | 输出文件里该维度的坐标名，默认取参数名 |
| 输出量 | 不勾选则输出场景中全部量 |
| 带平均 | 可选，按 µm 波段计算带平均值与带积分，一并写入 |
| 输出文件 | 扩展名决定格式：`.h5` 为 HDF5，`.csv` 为长表 |
| 断点续跑 | 中断后再次运行时跳过已完成的组合 |

对话框会显示组合总数和每个组合需要的内核运行次数。运行期间可取消，已完成部分保留。

### HDF5 文件布局

```
/<量名>                       [维度1, …, 维度N, 光谱]     数据，单位在属性 units
/bands/<量名>_average         [维度1, …, 维度N, 波段]     带平均
/bands/<量名>_integral        [维度1, …, 维度N, 波段]     带积分
/coords/wavenumber            [光谱]                     cm⁻¹
/coords/wavelength_um         [光谱]                     µm
/coords/<列名>                [取值数]                   各维度坐标（数值或字符串）
/coords/band                  [波段]                     波段名
/filled                       [维度1, …, 维度N]          1 = 该组合已计算
根属性：kernel、kernel_version、created_utc、base_scenario（基准场景 JSON）、plan（扫描计划 JSON）
```

在 Python 中读取（需要 h5py）：

```python
import h5py
with h5py.File("lut.h5") as f:
    T = f["Transmittance"][...]            # 形状 [维度1, …, 光谱]
    nu = f["coords/wavenumber"][...]
    tgt = f["coords/target_km"][...]
```

安装目录 `pyqradtran\read_lut_h5.py` 是一个现成的查看脚本。

### CSV 长表

每行一个 (维度值…, 波数, 量名, 值)；带平均另存为 `<文件名>.bands.csv`。适合 Excel 透视或 pandas 读取。

## 8. 命令行工具

`qradtran-cli.exe` 在安装目录下；勾选了「加入 PATH」的话可在任意位置使用。

```
qradtran-cli example --out case.json         生成一个模板场景文件
qradtran-cli validate case.json              检查参数
qradtran-cli plan case.json                  列出将执行的内核运行，不计算
qradtran-cli run case.json --out out.csv     计算并输出 CSV（--unit um|nm|cm-1  --density cm-1|nm|um）
qradtran-cli run case.json --out out.json    输出 JSON（含元数据）
qradtran-cli batch-example --out plan.json   生成参数扫描模板
qradtran-cli batch plan.json --out lut.h5    批量计算（.h5 或 .csv；--resume 断点续跑）
qradtran-cli kernel-info                     显示内核状态与可用分辨率
```

退出码：0 成功，1 参数错误，2 校验失败，3 内核失败。场景文件与 GUI 保存的工程文件通用。

## 9. Python 接口

安装目录下的 `pyqradtran\` 是一个 Python 包，针对 Python 3.10 64 位构建。使用前把安装目录加入 `PYTHONPATH`：

```bat
set PYTHONPATH=C:\Program Files\QRadtran
python
```

```python
import pyqradtran as qr

s = qr.Scenario.standard("MidlatitudeSummer")
s.geometry.mode = "SlantPath"
s.geometry.observer_alt_km = 0.0
s.geometry.target_alt_km = 10.0
s.geometry.view_zenith_deg = 30.0
s.aerosol.type = "Rural"
s.aerosol.visibility_km = 23.0
s.spectral.set_range(3, 5, unit="Micrometer", step=0.01, resolution="Coarse")
s.outputs.transmittance = True
s.outputs.path_radiance = True

r = qr.run(s)
nu = r.wavenumber                   # numpy 数组，cm⁻¹
T = r["Transmittance"]
L = r.series("PathRadiance", per="Micrometer")     # 换算为每 µm
print(r.band_average("Transmittance", 3.0, 5.0))  # {'average':…, 'integral':…}
r.to_csv("out.csv", unit="Micrometer")

# 参数扫描
plan = qr.BatchPlan()
plan.base = s
plan.add_dimension("/geometry/target_alt_km", [1, 2, 5, 10], "tgt_km")
plan.add_band("MWIR", 3.0, 5.0)
qr.batch(plan, "lut.h5")
```

完整示例见 `pyqradtran\python_quickstart.py`。绑定与图形界面共用同一核心库与内核，结果完全一致。

| 项目 | 说明 |
|---|---|
| uvspec.exe / libRadtran 数据目录 | 内核位置，默认指向安装目录下的 `kernels\libradtran`。一般不需要改 |
| 检测内核 | 显示内核版本与已安装的分辨率档位 |
| 最大并发内核进程 | 0 为自动（CPU 核数减 1）。内存紧张时调小 |
| 单次内核超时 | 秒。细分辨率、宽波段、高流数的计算可能需要调大 |
| 失败时保留工作目录 | 内核失败时保留输入输出文件供诊断，位置在日志中给出 |
| 成功时也保留工作目录 | 诊断用，平时关闭 |
| 界面语言 | 跟随系统，或固定为八种语言之一；重启后生效 |

工作目录位于 `%LOCALAPPDATA%\WaveFront\QRadtran\runs\`。

## 11. 计算原理简述与精度说明

- **内核**：libRadtran 2.0.6 的 uvspec，以独立进程调用；分子吸收用 REPTRAN 代表波长带模式（基于 HITRAN 2004 及后续），多次散射用 DISORT。
- **斜程透过率**：太阳波段由两个高度层的直射辐照度之比得到；热红外波段由地表温度扰动前后两次运行的辐射亮度差之比得到。
- **水平与近水平路径**：由所在层的垂直透过率导出消光系数，再沿球面几何路径积分。
- **路径辐射亮度**：观测者处辐射亮度减去目标处辐射亮度乘以透过率。
- **精度**：与 MODTRAN4 在长波与中波大气窗区对标，8 个算例中 6 个的窗区带平均透过率偏差在 0.04 以内，最好者 0.003；强吸收带内两代谱学数据存在系统差异。详见随软件文档《验证报告》。
- **REPTRAN 三档**：细 1 cm⁻¹ 与 MODTRAN 的 1 cm⁻¹ 带模式同级；粗 15 cm⁻¹ 适合快速估算。

## 12. 常见问题

**启动后状态栏显示「内核不可用」。**
安装目录被移动或 `kernels\libradtran` 被杀毒软件误删。打开设置检查路径；必要时重新安装。

**运行按钮是灰色的。**
参数面板下方有红色校验提示，按提示修正。常见原因：目标高度与观测者相同却选了斜程；天顶角方向与目标上下关系矛盾；光谱起止相同。

**计算失败，日志里有「Netcdf error … reptran_…_medium」。**
所选分辨率的数据表缺失。完整安装包含全部三档；若使用精简包，请改用「粗」分辨率或补装数据。

**热红外透过率全是 0。**
0.2.0 之前的版本在选择两流求解器时会出现，已修复：需要辐射亮度时自动改用 DISORT。

**计算很慢。**
细分辨率加宽波段加 32 流最慢。先用粗分辨率确定参数，最后再用细分辨率出图；批量计算时开足并发进程。

**曲线图右轴数值看不懂。**
右轴是辐射量，单位随工具栏「谱密度」切换：每 cm⁻¹、每 nm 或每 µm。表格与 CSV 用同一设置。

**Python 报「DLL load failed」。**
`PYTHONPATH` 须指向安装目录本身（包含 `qradtran_core.dll` 和 `Qt6Core.dll` 的那一层），不是 `pyqradtran` 子目录；Python 须为 3.10 64 位。

**界面显示成了英文。**
Windows 显示语言不在支持列表内时软件退回英文。到「工具 → 设置 → 界面语言」选择需要的语言并重启。

**能否用自己的 libRadtran？**
可以。在设置里把 uvspec.exe 与数据目录指向自己的版本，需为 2.0.x。
